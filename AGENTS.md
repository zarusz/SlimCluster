# Repository Instructions

- Name new git branches with the `feature/` prefix unless the user explicitly asks for a different branch name.
- Consult the [roadmap](docs/Roadmap.md) when planning work. Update it when a change completes a roadmap item or changes its scope.
- Update the **Unreleased** section of [ChangeLog.md](ChangeLog.md) in the same pull request as any user-facing change. Summarize the impact and include any configuration or migration steps users need.
